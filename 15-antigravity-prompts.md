# Antigravity Prompt Library

## Purpose

This document contains implementation prompts for Antigravity.

Every prompt should reference the approved project documentation rather than repeating requirements.

---

# Prompt Rules

Every prompt must include:

* Objective
* Scope
* Constraints
* Files to Follow
* Expected Output

---

# Files to Follow

Always reference:

* 01-master-prd.md
* 02-technical-architecture.md
* 03-brand-principles.md
* 04-visual-design-system.md
* 05-motion-system.md
* 06-ui-system.md

Additional files are included depending on the feature being built.

## Scope

## Constraints

* Do not change typography.
* Preserve responsiveness.
