# Build Roadmap

## Purpose

This document defines the implementation order for Yathin's Catalogue.

The objective is to build the product incrementally, validating quality after every milestone instead of building everything at once.

---

# Development Philosophy

Build.

Review.

Improve.

Lock.

Repeat.

Every milestone must be production-ready before moving to the next.

---

# Milestone 1 — Project Foundation

Goal

Prepare a production-ready frontend foundation.

Deliverables

* Next.js project setup
* TypeScript configuration
* Tailwind CSS
* shadcn/ui
* Framer Motion
* GSAP
* Lenis
* Folder structure
* Global theme
* Fonts
* Design tokens

Acceptance Criteria

* Builds successfully
* Clean architecture
* Responsive foundation
* Dark theme working
