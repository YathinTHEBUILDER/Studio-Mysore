# Visual Design System

## Purpose

This document defines the visual language of Studio Mysore.

It establishes the rules for typography, colour, spacing, layouts, imagery and visual hierarchy.

Every page should feel like part of the same family while allowing each industry to express its own personality.

---

# Design Philosophy

The interface should feel:

* Calm
* Premium
* Intentional
* Human
* Elegant
* Timeless

The design should never compete with the content.

Instead, it should quietly support it.

---

# Design Principles

## Simplicity

Remove unnecessary visual noise.

Every element should have a purpose.

---

## Hierarchy

Visitors should always know where to look first.

Typography, spacing and contrast create hierarchy—not decoration.

---

## Consistency

Spacing.

Sizing.

Corners.

Motion.

Everything should feel predictable.

Consistency builds trust.

---

## Whitespace

Whitespace is part of the design.

Never fill empty space without purpose.

Large margins create clarity.

---

# Theme

Dark-first.

Minimal.

Editorial.

Professional.

Premium without feeling exclusive.

# Industry Accent Colours

Each experience receives one subtle accent colour.

The foundation remains identical.

Example direction:

☕ Café

Warm coffee brown.

---

🍽 Restaurant

Deep burgundy.

---

🦷 Dental

Cool blue.

---

🏥 Medical Clinic

Soft teal.

---

🏋️ Gym

Slate blue or muted orange.

Accent colours should support the atmosphere rather than dominate it.

---

# Typography

## Display Font

Clash Display

Used for:

* Hero headlines
* Major section titles
* Key statements

---

## Body Font

Inter

Used for:

* Navigation
* Buttons
* Forms
* Paragraphs
* Supporting text

---

# Typography Hierarchy

Display XL

Homepage hero.

Display L

Section introductions.

Heading

Content headings.

Body

Descriptions.

Caption

Supporting information.

Avoid excessive font weights.

Hierarchy should come from size and spacing.

---

# Layout

Primary layout uses a 12-column responsive grid.

Editorial moments may intentionally break the grid to create emphasis.

The grid should never be abandoned completely.

---

# Containers

Standard

Narrow

Wide

Full Width

Each page should use consistent container widths.

---

# Spacing Scale

4

12

16

24

Whitespace should feel generous.

---

# Border Radius

Small

10px

Medium

16px

Large

24px

Avoid exaggerated rounding.

---

# Elevation

Use contrast before shadows.

Shadows should be soft and subtle.

Depth should come from spacing and layering.

---

# Borders

Thin.

Low contrast.

Never dominant.

Borders define structure without attracting attention.

---

# Photography

Photography should feel editorial.

Show real environments.

Capture genuine moments.

Preferred:

* Coffee preparation
* Fresh food
* Treatment rooms
* Gym equipment
* Product details

Avoid:

* Office meetings
* Handshakes
* People pointing at screens
* Generic smiling teams
* AI-generated artwork

Every image should support the story.

---

# Icons

Lucide React.

Minimal.

Outline style.

Consistent sizing.

Use icons only when they improve clarity.

---

# Illustrations

Do not use decorative illustrations.

The interface itself should communicate the experience.

---

# Device Mockups

Use realistic devices.

Phone.

Tablet.

Laptop.

The device should feel like a product being demonstrated—not a decorative frame.

---

# Visual Rhythm

Alternate section density.

Example:

Hero

↓

Compact problem section

↓

Large storytelling section

↓

Interactive demo

↓

Compact explanation

↓

Large CTA

Rhythm keeps scrolling engaging.

---

# Visual Hierarchy

Every section should answer:

What is the first thing the visitor notices?

What is the second?

What action should they take?

If these answers are unclear, simplify the layout.

---

# Responsive Philosophy

Every breakpoint should feel intentionally designed.

Never simply resize layouts.

Adapt them.

---

# Accessibility

High contrast.

Readable typography.

Clear focus states.

Comfortable touch targets.

Support reduced motion.

Accessibility is part of premium design.

---

# Performance

Design decisions should support performance.

Avoid unnecessarily heavy assets.

Optimise imagery.

Keep animations lightweight.

Fast feels premium.

---

# Visual Checklist

Before approving a design:

* Does it communicate clearly?
* Is there enough whitespace?
* Is the hierarchy obvious?
* Does it feel premium?
* Does it match the brand?
* Does it perform well?
* Does it work beautifully on every device?

If any answer is "no", iterate.

---

# Decisions Made

* Dark-first interface.
* Editorial photography.
* Clash Display + Inter.
* 12-column responsive grid.
* Subtle industry accents.
* Whitespace as a primary design tool.
* Performance considered part of design.
