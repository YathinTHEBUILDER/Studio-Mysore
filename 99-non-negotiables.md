# Studio Mysore Constitution

These rules apply to every page, component and feature.

Breaking these rules requires an approved design decision.

---

# Product

1. Every page has one purpose.

2. Every page leads naturally to a WhatsApp conversation.

3. Business value comes before visual effects.

4. Every feature solves a real problem.

5. Every experience ends with trust.

---

# Design

6. Whitespace is intentional.

7. Typography creates hierarchy.

8. Never use decorative clutter.

9. Every image supports the story.

10. Editorial photography over generic stock imagery.

---

# Motion

11. Every animation has a purpose.

12. Every page has one hero moment.

13. Motion should guide, not distract.

14. Respect reduced motion preferences.

15. Performance is more important than flashy effects.

---

# Engineering

16. Build once. Reuse everywhere.

17. No duplicated components.

18. TypeScript only.

19. Accessibility is mandatory.

20. Mobile quality must equal desktop quality.

21. Server Components by default.

22. Client Components only when necessary.

---

# Copy

23. Write like a person.

24. Never use AI-sounding marketing language.

25. Explain business outcomes instead of software features.

26. Keep headlines short.

27. Keep paragraphs concise.

---

# User Experience

28. Never overwhelm the visitor.

29. Every interaction provides feedback.

30. Every button clearly describes what happens next.

31. Visitors should always know the next step.

---

# Studio Mysore

32. Understand the business before proposing a solution.

33. Build around the way the business works.

34. Stay involved after launch.

35. Details build trust.

36. Simplicity is a feature.

37. Every pixel should have a reason to exist.

38. If a feature doesn't help win a client, remove it.

39. Quality is never rushed.

40. Every product should feel intentionally crafted.

---

# Final Principle

**We don't build websites.**

**We build digital experiences around the way businesses work.**
